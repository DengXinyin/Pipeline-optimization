# metage v2.88.2 优化说明

`metage v2.88.2` 基于 `metage_megahit_no_v2.87` 优化而来。本文件记录当前代码和 WDL 中已经实现的主要改动，便于后续维护和版本核对。

## 1. 物种注释性能与稳定性

- `tax_anno` 使用 V2 DIAMOND 注释实现，工作流中固定使用 `--fast`，以速度优先。
- 当前生效 WDL 将 DIAMOND `--block-size` 固定为 `8`；V1/V2 脚本均保留了可配置 block size，并在 OOM 时自动降低 block size 后重试。
- 注释脚本补充了日志、输入检查及空 DIAMOND 输出保护，避免空结果导致下游 pandas 解析失败。

## 2. 新增与扩展的数据库分析

- 新增 COG 注释、丰度统计和差异分析模块。
- 新增 MetaCyc 注释、丰度统计和差异分析模块。
- 新增 Kraken2 物种注释模块：`kraken2_anno`、`kraken2_tax_base`、`kraken2_tax_diff`。
  - Kraken2 由 `use_kraken2` 参数控制，为可选分析；未启用时工作流自动跳过。
  - COG 和 MetaCyc 为常规流程输出。

## 3. 基因与物种注释结果增强

- KEGG 结果补充物种分类谱系信息：界、门、纲、目、科、属、种。
- 新增 `GeneAnnotationSummary`：以 `Gene_ID` 为键，汇总 eggNOG/KEGG、COG、MetaCyc、CycDB、ARG、VFDB、mobileOG、BacMet2 和 QS 等数据库注释。
- 最终 `resFile` 中保留各数据库汇总结果，便于按基因检索多库注释。

## 4. 增量与复用运行

- 新增 `full`、`incremental`、`reuse` 三种运行模式。
- 使用项目级 `data/sample_registry.tsv` 记录样本和文件状态；成功运行后自动更新，供下一次增量或复用运行使用。
- 新增增量计划、注册表应用与提交、上游结果合并、注册表 MD5 驱动的缓存失效，以及样本/文件一致性检查。
- 增量模式只对新增或变更样本执行上游分析，并合并既有有效结果。

## 5. 结果展示与交付

- 新增统一绘图样式配置，可集中设置主题、字体、字号、图例和配色。
- 使用最终元数据重新绘制 QC 图，并在结果目录中将内部样本 ID 替换为展示名称。
- 更新报告、结果收集、resFile 生成及 WDL 参数转换相关脚本。

## 6. Kraken2 结果进入最终结果目录（后续补充）

启用 Kraken2 时，以下节点的结果会被收集至最终 `resFile/Result/17-Kraken2/`，不新增 PDF/Word 报告章节：

- `call-kraken2_anno`：原始物种注释结果；
- `call-kraken2_tax_base`：物种组成与统计结果；
- `call-kraken2_tax_diff`：物种差异分析结果。

未启用 Kraken2 时，不会生成该目录，常规流程不受影响。
