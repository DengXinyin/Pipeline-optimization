============================================================
 宏基因组流程优化项目 — 使用说明
============================================================

本项目是 metage_megahit.wdl 的优化记录，私有仓库。

一、服务器端操作
------------------------------------------------------------

1. 首次配置（已完成，以后不用管）：

   SSH 密钥已生成并添加到 GitHub，密钥有密码保护。
   登录服务器后，.bashrc 自动提示输入密钥密码（一次即可）。

2. 日常同步：

   在服务器上完成 task 运行、记录时间后，终端输入：

       sync "更新说明"

   例如：

       sync "完成 Task 17 tax_diff 原代码运行，real 45m30s"
       sync "Task 17-18 优化完成，更新统计表和日志"

   脚本自动完成：
   - 拉取 GitHub 仓库到临时目录
   - 从工作目录复制文档/日志/代码
   - 提交并推送
   - 删除临时文件（服务器不留痕迹）

3. 如果 sync 命令不可用：

       source ~/.bashrc

4. 如果提示权限错误：

       ssh-add ~/.ssh/id_ed25519
       输入密钥密码

二、哪些文件会被同步
------------------------------------------------------------

   以下文件从服务器工作目录自动同步到 GitHub：

   scripts_dxy/
   ├── Metagenomic_pipeline_optimization_kimi.Qmd   → AI 维护展示文档
   ├── Metagenomic_pipeline_overall.qmd              → 流程总览
   ├── Readme_dxy.Qmd                                → 用户优化记录
   ├── Todo_list.txt                                 → 工作流规范
   ├── 宏基因组优化效率统计.xlsx                      → 效率统计表
   ├── logs/                                         → 运行日志（全部）
   └── Script/                                       → 优化代码（全部）

三、版本控制
------------------------------------------------------------

   每次 git push 都是完整快照，历史永不会丢失。

   查看历史版本：
   - 在 GitHub 网页上点 "Commits" 查看所有提交
   - git log --oneline  列出提交历史
   - git checkout <commit>  恢复任意历史版本

   大版本打标签（可选）：
       git tag -a v1.0 -m "完成第一轮优化"
       git push --tags

四、需要保密的内容
------------------------------------------------------------

   - GitHub 仓库：私有（Private），仅你可见
   - 服务器：SSH 密钥有密码保护，别人登录也无法推送
   - 数据库路径、内网 IP：在 GitHub 上可见，但仓库本身是私有的

五、添加协作者（如需）
------------------------------------------------------------

   1. 打开 https://github.com/DengXinyin/Pipeline-optimization/settings/access
   2. 点击 "Add people"
   3. 输入对方 GitHub 用户名
   4. 选择权限（Read / Write）
